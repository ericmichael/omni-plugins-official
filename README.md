# omni-plugins-official

Official skill bundles for [Omni Code Launcher](https://github.com/omni-code/launcher).

## Bundles

- **git-workflow** — `commit`, `debug`, `land`, `pull`, `push`
- **dev-essentials** — `software-planning`, `playwright-cli`, `webapp-acceptance-runner`
- **omniagents** — `omniagents-basic`

## Install

In Omni Code Launcher, open Settings → Skills → **Install from marketplace**, then enter:

```
ericmichael/omni-plugins-official
```

Pick a bundle and click **Install**.
